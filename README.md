# فروشگاه شفق

فروشگاه فارسی و راست‌به‌چپ پوشاک زنانه، با فرانت‌اند واکنش‌گرا، سرور Node.js و دیتابیس SQLite. بدون وابستگی npm.

## اجرا

نیازمند Node.js نسخه 22.13 یا بالاتر:

```powershell
npm start
```

فروشگاه: http://localhost:3000 — مدیریت سفارش‌ها: http://localhost:3000/admin

برای ساخت حساب مدیر (یا بازنشانی رمز آن) در ترمینال پروژه اجرا کنید:

```powershell
npm run admin:setup
npm start
```

دستور اول نام کاربری و رمز ۱۲ تا ۱۲۸ نویسه‌ای می‌پرسد؛ رمز هنگام تایپ نمایش داده نمی‌شود. سپس در `/admin` وارد شوید. رمز پیش‌فرض و راه‌اندازی عمومی از طریق وب وجود ندارد. `ADMIN_KEY` و رمز ثابت قبلی دیگر پذیرفته نمی‌شوند. فایل `.env` خودکار خوانده نمی‌شود. پس از تغییر کد، سرور قدیمی را با `Ctrl+C` متوقف و مجدداً اجرا کنید.

## پنل مدیریت

- مشاهده، جستجو، افزودن و ویرایش نام، قیمت، تخفیف، توضیحات، برچسب و تصویر محصول
- تصویر از طریق آدرس مستقیم HTTPS؛ بارگذاری فایل تصویر پیاده‌سازی نشده است
- ترکیب‌های دلخواه سایز و رنگ با موجودی مستقل؛ دسته‌ها و گزینه‌ها در فروشگاه پویا هستند
- انتشار یا پیش‌نویس؛ حذف قابل بازیابی با حفظ سابقه سفارش‌ها؛ بازیابی به‌صورت پیش‌نویس
- ایجاد و تغییر نام دسته‌بندی؛ حذف دسته فقط در صورت نداشتن محصول، شامل محصولات حذف‌شده
- مشاهده سفارش‌ها، جستجو و تغییر وضعیت: بررسی ← آماده‌سازی ← ارسال ← تحویل؛ کد رهگیری برای ارسال لازم است
- لغو سفارش پیش از ارسال، با برگشت یک‌باره موجودی؛ وضعیت پرداخت به‌صورت خودکار تغییر نمی‌کند
- ثبت تاریخچه عملیات مدیر؛ نمایش ۱۰۰ فعالیت اخیر
- کنترل نسخه محصول برای جلوگیری از بازنویسی موجودی تغییرکرده؛ در صورت تعارض اطلاعات را تازه کنید

## کنترل‌های امنیتی پیاده‌شده

رمز با scrypt و salt تصادفی ذخیره می‌شود. نشست تصادفی در کوکی HttpOnly و SameSite=Strict قرار می‌گیرد و فقط هش شناسه نشست در دیتابیس ذخیره می‌شود. نشست پس از ۳۰ دقیقه عدم فعالیت یا حداکثر ۸ ساعت منقضی می‌شود. خروج و بازنشانی رمز نشست را باطل می‌کند. رمز در کد، لاگ یا localStorage قرار نمی‌گیرد.

عملیات مدیریت به نشست معتبر، توکن CSRF و Origin همسان نیاز دارد. پس از ۵ تلاش ناموفق، ورود از همان آدرس اتصال برای ۱۵ دقیقه محدود می‌شود. برنامه X-Forwarded-For را اعتماد نمی‌کند؛ پشت پراکسی همه کاربران ممکن است آدرس اتصال مشترک داشته باشند. اعتبارسنجی ورودی، SQL پارامتری، محدودیت اندازه درخواست، escape خروجی، CSP و محافظت در برابر iframe اعمال شده‌اند. HTTPS برای محیط اینترنتی ضروری است؛ این کنترل‌ها تضمین امنیت مطلق یا جایگزین بررسی استقرار نیستند.

برای استقرار پشت پراکسی HTTPS، `NODE_ENV=production` و `APP_ORIGIN=https://your-domain` را تنظیم کنید. پراکسی باید Host اصلی را حفظ کند؛ در محیط production کوکی Secure می‌شود. سرویس همچنان روی loopback می‌ماند و باید از طریق پراکسی در دسترس قرار گیرد. گواهی و پراکسی در این پروژه نصب نشده‌اند. دسترسی سیستم‌عامل به دیتابیس و اسکریپت بازنشانی مدیر را محدود کنید و از دیتابیس پشتیبان بگیرید.

## امکانات

- دسته‌بندی، جستجو، مرتب‌سازی قیمت و علاقه‌مندی‌ها
- انتخاب سایز و رنگ با موجودی مستقل هر ترکیب
- سبد خرید پایدار در مرورگر و فرم آدرس با پشتیبانی ارقام فارسی
- محاسبه مبلغ و ارسال در سرور و ذخیره تراکنشی سفارش با جلوگیری از فروش بیش از موجودی
- پنل مدیریت محصولات، دسته‌بندی‌ها، سفارش‌ها و تاریخچه فعالیت با ورود مدیر
- نمایش مناسب موبایل، دیالوگ‌های قابل بستن با Escape و کنترل‌های دارای برچسب

دیتابیس در `data/store.db` هنگام اولین اجرا ساخته و با هشت محصول نمونه پر می‌شود. مسیر دیتابیس با `DB_PATH` و پورت با `PORT` قابل تنظیم است. از فایل دیتابیس و فایل‌های WAL هنگام اجرای سرور با روش پشتیبان‌گیری سازگار SQLite نسخه پشتیبان بگیرید. سرور به صورت پیش‌فرض فقط روی `127.0.0.1` در دسترس است.

## بررسی

```powershell
npm test
```

۱۰ تست با دیتابیس مجزا اجرا می‌شوند: محاسبه قیمت و موجودی، تراکنش ناموفق، ارسال رایگان، ورود و انقضای نشست، خروج، محدودیت تلاش ورود، CSRF و Origin، اعتبارسنجی محصول، تعارض ویرایش، حذف و بازیابی، مدیریت دسته و برگشت یک‌باره موجودی سفارش لغوشده.

## پیش از استفاده تجاری

این نسخه برای پیش‌نمایش و ثبت سفارش آزمایشی است. تصاویر Unsplash تصاویر استایل نمونه‌اند و لزوماً خود محصول نیستند. نام، قیمت، موجودی، جدول سایز، هزینه ارسال و قوانین فروش نمونه هستند. تصاویر و فونت گوگل به اینترنت نیاز دارند؛ فونت جایگزین سیستمی در نظر گرفته شده است.

برای فروش واقعی باید محصولات و عکس‌های واقعی، اطلاعات تماس و سیاست فروش وارد شوند؛ درگاه و تأیید پرداخت سمت سرور، محافظت ضداسپم سفارش‌های عمومی، HTTPS، پشتیبان‌گیری و میزبانی دائمی تکمیل شوند. سفارش آزمایشی از موجودی نمونه کم می‌کند. هیچ پرداخت، پیامک یا ارسال واقعی انجام نمی‌شود. ورود دومرحله‌ای و نقش‌های چندمدیره در این نسخه وجود ندارند.
